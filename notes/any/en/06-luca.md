# Luca

1. SD. Go right and up to the next screen, CS (2:30). Do not save.
2. SD in locker room, **Exit the Blitzball tutorial**. SD, walk down the corridor and SD.
3. Walk south to the next screen, SD. Whistle CS (0:30). Walk right to the next screen.
4. SD, run up to the Cafe. SD, then Skippable FMV + CS (0:30), SD. Run left to the next screen.

:::optional If Tidus already has 5 Sphere Levels: get Haste early
:::use luca-tidus
5. **Touch the Save Sphere** after doing the menu.
:::

6. Go left to the docks, talk to Oaka to shop for equipment.

:::shop | 3050 gil
- Sell: Any surplus equipment to go above 3050 gil. Avoid selling Official Ball, Lightning Steel and Thunder Ball if you received those early.
- Buy:
  - Stunning Steel, Equip

There are two chests further up the dock containing 600 Gil and Tidal Spear if you are still short on gil.
:::

7. SD after exiting Oaka shop, run north to next dock.

:::battle 1st and 2nd Machina Battles | 300HP each
party: Tidus, Kimahri, Lulu
SD
* *If Early Haste*
  * Tidus: Haste Lulu
* Tidus: Defend
* Kimahri: Defend
* Lulu: Thunder each Machina
:::

8. Right north to next screen after the 1st Machina battle, and repeat the above strategy for the 2nd Machina battle.

:::optional If Tidus already has 5 Sphere Levels: get Haste early
:::use luca-tidus
:::

9. Run right to the next screen after the 2nd Machina battle.

:::battle 3rd Machina Battle | 300HP each
SD during battle.
* *If Early Haste (All Waves)*
  * Tidus: Haste Lulu, then Defend
  * Kimahri: Defend
  * Lulu: Thunder
* *Else: 1st Wave*
  * Tidus: Attack x2
  * Kimahri: Lancet the same Machina as Tidus
  * Lulu: Thunder the other Machina
* *2nd Wave*
  * Tidus: Defend
  * Kimahri: Defend
  * Lulu: Thunder each Machina
* *3rd Wave*
  * Tidus: Attack x2
  * Kimahri: Attack
  * Lulu: Thunder the other machina
  * Kimahri: Seed Cannon

Tidus and Kimahri focus on one Machina, Lulu the other for the 1st and 3rd waves
:::

10. Heal with potions if anyone is in critical HP, or **Touch the Save Sphere** if you have used Haste early.
11. Do the following Sphere Grid if Tidus now has 5 Sphere Levels, otherwise you can proceed to the boss fight.

:::spheregrid
* Tidus:
  * Move ↓ ↘ ↘
  * +1 Str, +20 MP, Haste
route: luca-tidus
:::

12. Run right, CS (0:30)

:::battle Oblitzerator | 3,000HP
party: Tidus, Kimahri, Lulu
SD
* *If got Haste*
  * Tidus: Haste Lulu
* Tidus: Defend
* Kimahri: Defend
* Lulu: Thunder Crane x3
* Tidus: Use crane after three hits
* CS (0:20)
* Kimahri: Defend
* Lulu: Thunder
* Tidus: Attack
Look out for Lightning Steel drop (20% chance) or Thunder Ball drop (7.5%)
:::

13. CS (2:00), SD during and after the Blitzball game.

:::optional If Tidus has only just got 5+ Sphere Levels: get Haste now
:::use luca-tidus
:::

14. Run south through the next two screens. **Touch the Save Sphere**, and **Auto-Sort** items
15. Run north to locker room. Small Cutscene Skip if you press Select while Wakka is grunting on the bench. SD after.
16. Go back into the locker room, speak to Wakka, SD then CS (1:20). SD after Lulu scene, and CS for Auron arrival (1:40)
