# Mi'ihen Highroad

1. Run north to Raldo tutorial, 1 Guaranteed Power Sphere, bonus sphere if Overkill.
2. **Formation:** Tidus, Wakka, Auron
3. Run north further and SD for Maechen scene.
4. Flee from all encounters. Heal if Tidus is low HP.

:::skip Mi'ihen Skip
:::

4. Even if you fail the skip, make sure you speak to the man in blue to get a Hunter's Spear.
5. Go to the next screen, run up and SD during Calli scene.
6. Run up to the next screen, watch a small scene with a chocobo cart, and Gatta scene. 
7. SD during Shelinda scene if not doing skip, run up to exit area.
