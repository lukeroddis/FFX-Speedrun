Tools

Tools for planning routes and keeping the notes up to date.

Sphere Grid Route Builder

Build a Sphere Grid route: moves, activations, unlocks and teleports for any character, with Sphere Levels and spheres counted. Export it for the notes, or use it for your own challenge runs.

Sphere Grid Editor

For contributors: edit the Sphere Grid data itself, the nodes and links that every grid on the site draws.

FFX Speedrun Mod

A program facilitating the speedrunning of FFX on PC. Used for the TrueRNG% category or for setting a seed for Any%.

FFX RNG Tracker

A program to help track the RNG during the FFX speedrun, used in Any%.
