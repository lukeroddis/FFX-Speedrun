Tools

Tools for planning routes and keeping the notes up to date.

Sphere Grid Route Builder

Build a Sphere Grid route by clicking: moves, activations, unlocks and teleports for any character, with Sphere Levels and spheres counted. Export it for the notes, or use it for your own runs and challenge runs.

Sphere Grid Editor

For contributors: edit the Sphere Grid data itself, the nodes and links that every grid on the site draws.
