Map Editor

← Tools How maps work

1 · REFERENCE SCREENSHOT

Opacity

A screenshot of the in-game map to trace over. It stays on your computer and never goes into the notes; the map's shape is taken from it.

2 · DRAW

Trail: click along the paths you can walk, one line per path. Route: click along the way to go, in order. Press Enter or New line to start another line.
Chest / Label: click a spot, then type its name. Chest names are found in the glossary, so they get their icon.
Drag a point of the chosen kind to move it. Right-click any point to remove it.
Names: drag a chest's or label's name off the paths it covers; a thin line joins it to its spot. Double-click a name to put it back.

3 · SAVE THE MAP FILE

Save it as notes/maps/<name>.txt. Maps have no language, so every category's notes can use the same one.
